## 🏗️ Featured Project

<div align="center">

### 🚛 Droptransit — Multi-tenant SaaS for Transport at Scale

</div>

A **production SaaS platform** built solo, end-to-end, for transport companies operating internationally.

**🚀 What it does:**
Fleet management · Real-time tracking · Multi-currency billing · Stripe subscriptions · Digital contracts with e-signatures · CRM · Warehouses & inventory · Public REST API for integrations

**🏛️ Architecture:**
Hexagonal architecture · Multi-tenant data isolation · 7-role access control · Per-tenant custom branding · OpenAPI-documented public API

**🧰 Stack:**
`React` · `TypeScript` · `FastAPI` · `PostgreSQL` and more..
